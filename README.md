## NEXORA

```
                    NEXORA
                       │
        ┌──────────────┼──────────────┐
        │              │              │
       AI          SECURITY         CLOUD
        │              │              │
        └──────────────┼──────────────┘
                       │
                 NEXORA CORE
          Identity · Billing · API · Registry
```

One platform, three pillars, shared core — not a pile of unrelated repos. Every product below shares the same account, billing, and API surface.

### 🛡️ Security
- **[Vigilo](https://github.com/xsmartbartx/Vigilo)** — live security and compliance scanning for AI-generated web apps · [vigilo.onenexora.com](https://vigilo.onenexora.com)
- **[NeuraWall](https://github.com/xsmartbartx/NeuraWall)** — AI-assisted network firewall and anomaly detection · [neurawall.onenexora.com](https://neurawall.onenexora.com)
- **[AI_Cloud_Log_Anomaly_Detection_System](https://github.com/xsmartbartx/AI_Cloud_Log_Anomaly_Detection_System)** *(Sentinel)* — statistical + rule-based log anomaly detection · [sentinel.onenexora.com](https://sentinel.onenexora.com)
- **[AI-Driven-CSPM](https://github.com/xsmartbartx/AI-Driven-CSPM)** — cloud security posture management with AI risk analysis · [cspm.onenexora.com](https://cspm.onenexora.com)
- **[Secure_AI_API_Gateway](https://github.com/xsmartbartx/Secure_AI_API_Gateway)** *(Gateway)* — governed front door for AI/LLM API access · [gateway.onenexora.com](https://gateway.onenexora.com)
- **[Secure_LLM_API_Kubernetes](https://github.com/xsmartbartx/Secure_LLM_API_Kubernetes)** — secure LLM API, built for Kubernetes
